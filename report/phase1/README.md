# Phase 1 — corpora and tokenizers

Everything graded for Phase 1. Two independent pipelines, one per language.

## Per language

One report each, covering corpus and tokenizer together:

- [`gujarati/README.md`](gujarati/README.md) — Model H
- [`nepali/README.md`](nepali/README.md) — Model L

## Cross-language tables

Both languages side by side. All generated by `make_report_assets.py`; do not
edit by hand.

| File | Contents |
|---|---|
| `tables/corpus_summary.md` | every headline figure, raw documents through vocabulary utilisation |
| `tables/provenance.md` | manual vs public tokens by collection method, and the manual share of each split |
| `tables/pipeline_retention.md` | documents and characters surviving each stage |
| `tables/tokenizer_sweep.md` | both five-size vocabulary sweeps, chosen size marked |
| `tables/tokenization_examples.md` | worked tokenizations and the most frequent pieces |

## Machine-written summaries

`<lang>/json/` holds the raw output of each pipeline stage. These are the source
of truth — every number in the tables, figures and reports is derived from them.

| File | Written by |
|---|---|
| `cleaning.json` | `preprocess.py` |
| `dedup.json` | `deduplicate.py` |
| `splits.json` | `build_splits.py` |
| `corpus_stats.json` | `corpus_stats.py --tokenizer` |
| `tokenizer_sweep.json` | `tokenizer_stats.py --compare-sweep` |
| `tokenizer_stats.json` | `tokenizer_stats.py` |
| `*_frequency_curve.json` | piece-frequency data behind the Zipf figures |

## Regenerating

After both language pipelines have finished:

python3 report/phase1/make_report_assets.py
