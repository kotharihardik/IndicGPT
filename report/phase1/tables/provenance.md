# Token provenance

Manual versus public tokens over the whole corpus (all three splits), and the manual share of each split. Every document carries `manual_or_public` from collection onward, so these are counted, not estimated. Generated by `report/phase1/make_report_assets.py`; do not edit by hand.

| | Gujarati (Model H) | Nepali (Model L) |
|---|---:|---:|
| public dataset | 393,316,557 (68.56%) | 425,022,332 (78.42%) |
| **collected directly** | **180,350,586 (31.44%)** | **116,938,372 (21.58%)** |
| documents collected directly | 207,579 of 830,410 | 261,557 of 1,239,652 |

## Manual share of each split

| split | Gujarati (Model H) | Nepali (Model L) |
|---|---:|---:|
| train | 31.51% | 21.59% |
| validation | 31.64% | 21.18% |
| test | 29.95% | 21.68% |

The three splits agree to within about 1.6 points in each language, which is what a document-level hash split should give: provenance is not correlated with the hash, so it carries through the split unchanged.
